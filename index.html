01 — About

About Me

I'm a fresh Bachelor of Science in Information Technology (BSIT) graduate working toward becoming a Software Engineer.

Most of what I know so far, I learned by building things — a calculator in C++, a Windows Forms enrollment system in C#, a Java OOP project, and a browser-based finance tracker in HTML, CSS, and JavaScript. My code is beginner-level and I treat it that way, but I keep building, because that's the only way to actually improve.

Right now I'm focused on strengthening my programming fundamentals, getting more comfortable with web development, learning proper Git/GitHub workflow, and writing documentation that matches what the code actually does.

05 — Mindset

Developer Mindset

I believe software development is a loop, not a finish line.

Learn it→ Build it→ Break it→ Fix it→ Ship it→ Learn again

I don't expect to get things right on the first attempt. Most of what I've learned so far came from something not working, reading about why, and trying again. That cycle — learning, building, making mistakes, improving, growing — is the part of software development I'm most comfortable with.

Perseverance Curiosity Continuous Learning Building Improvement
